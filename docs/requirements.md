# 요구사항정의서

## 1. 프로젝트 개요

본 프로젝트는 대학교·공공기관의 부속 홈페이지 운영을 가정한 PHP 기반 통합관리 CMS입니다.

여러 학과, 연구소, 부속기관 홈페이지를 하나의 관리자 시스템에서 관리할 수 있도록 하며, 관리자 권한에 따라 사이트, 메뉴, 페이지, 게시판, 첨부파일, 배너, 팝업 등을 관리할 수 있도록 구현합니다.

## 2. 개발 목적

* PHP 기반 웹서비스 구축 경험 확보
* 홈페이지 CMS 구조 이해
* 관리자 화면과 사용자 화면을 모두 포함한 웹서비스 구현
* DB 설계부터 기능 구현, 테스트, 문서화까지 전체 개발 흐름 경험
* 웹에이전시/SI 환경에서 자주 요구되는 홈페이지 구축 및 유지보수 기능 구현

## 3. 사용자 유형

### 3.1 최고관리자

* 전체 사이트 관리
* 관리자 계정 관리
* 권한 관리
* 전체 게시판 및 콘텐츠 관리
* 관리자 작업 로그 확인

### 3.2 사이트관리자

* 담당 사이트 관리
* 담당 사이트의 메뉴 관리
* 담당 사이트의 페이지 관리
* 담당 사이트의 게시판 관리
* 배너 및 팝업 관리

### 3.3 콘텐츠관리자

* 게시글 작성/수정/삭제
* 첨부파일 업로드
* 일반 페이지 내용 수정

### 3.4 일반 사용자

* 홈페이지 조회
* 게시글 조회
* 게시글 검색
* 첨부파일 다운로드

## 4. 기능 요구사항

### 4.1 관리자 인증

* 관리자는 아이디와 비밀번호로 로그인할 수 있다.
* 비밀번호는 해시 처리하여 저장한다.
* 로그인한 관리자만 관리자 페이지에 접근할 수 있다.
* 로그아웃 시 세션을 종료한다.

### 4.2 권한관리

* 관리자는 권한에 따라 접근 가능한 메뉴가 달라진다.
* 최고관리자는 모든 기능에 접근할 수 있다.
* 사이트관리자는 담당 사이트의 기능만 관리할 수 있다.
* 콘텐츠관리자는 게시글 및 페이지 수정 중심의 기능만 사용할 수 있다.

### 4.3 사이트 관리

* 최고관리자는 부속 홈페이지를 생성할 수 있다.
* 사이트명, 사이트 코드, 설명, 사용 여부를 관리할 수 있다.
* 사용 중지된 사이트는 사용자 화면에 노출하지 않는다.

### 4.4 메뉴 관리

* 사이트별로 메뉴를 생성할 수 있다.
* 상위 메뉴와 하위 메뉴를 구성할 수 있다.
* 메뉴명, 연결 유형, 노출 여부, 정렬 순서를 관리할 수 있다.
* 메뉴는 일반 페이지 또는 게시판과 연결할 수 있다.

### 4.5 페이지 관리

* 일반 페이지를 생성, 수정, 삭제할 수 있다.
* 페이지 내용은 관리자 화면에서 입력한다.
* 페이지 수정 시 이전 내용을 이력으로 저장한다.
* 이전 버전의 내용을 확인할 수 있도록 한다.

### 4.6 게시판 관리

* 공지사항, 자료실, FAQ 게시판을 관리할 수 있다.
* 게시글을 작성, 조회, 수정, 삭제할 수 있다.
* 게시글 목록에서 검색과 페이징을 제공한다.
* 중요 공지글은 상단 고정이 가능하다.

### 4.7 첨부파일 관리

* 게시글에 첨부파일을 등록할 수 있다.
* 업로드 가능한 확장자를 제한한다.
* 저장 파일명은 난수화하여 파일명 충돌을 방지한다.
* 사용자는 첨부파일을 다운로드할 수 있다.

### 4.8 배너/팝업 관리

* 사이트별 메인 배너를 등록할 수 있다.
* 팝업 공지를 등록할 수 있다.
* 배너와 팝업은 노출 시작일과 종료일을 설정할 수 있다.
* 사용 여부에 따라 화면 노출을 제어할 수 있다.

### 4.9 관리자 작업 로그

* 관리자 로그인, 등록, 수정, 삭제 이력을 기록한다.
* 작업자, 작업 유형, 작업 대상, 작업 일시, IP 정보를 저장한다.

## 5. 비기능 요구사항

* PHP 8.x 환경에서 실행 가능해야 한다.
* MySQL 또는 MariaDB를 사용한다.
* DB 접근은 PDO를 사용한다.
* SQL Injection 방지를 위해 Prepared Statement를 사용한다.
* 비밀번호는 평문으로 저장하지 않는다.
* 업로드 파일은 확장자와 크기를 제한한다.
* Docker Compose 기반 실행 방법을 제공한다.
* README에 설치 및 실행 방법을 문서화한다.

## 6. 1차 개발 범위

1차 개발에서는 아래 기능을 우선 구현합니다.

* 관리자 로그인/로그아웃
* 관리자 권한관리
* 부속 홈페이지 관리
* 메뉴 관리
* 일반 페이지 관리
* 게시판 관리
* 첨부파일 업로드/다운로드
* 배너 및 팝업 관리
* 콘텐츠 수정 이력 관리
* 관리자 작업 로그 기록

# 화면목록

## 1. 문서 목적

본 문서는 대학 부속홈페이지 통합관리 CMS의 1차 개발 범위에서 구현할 화면을 정리하기 위한 문서입니다.

요구사항정의서와 DB 설계 초안을 바탕으로 관리자 화면과 일반 방문자 화면을 구분하고, 각 화면에서 제공할 주요 기능을 정의합니다.

본 문서는 초기 화면목록이며, 실제 구현 과정에서 화면명, URL, 기능 범위는 변경될 수 있습니다.

## 2. 화면 구분

본 프로젝트의 화면은 크게 두 영역으로 나눕니다.

| 구분        | 설명                                      |
| --------- | --------------------------------------- |
| 관리자 화면    | 최고관리자, 사이트관리자, 콘텐츠관리자가 로그인 후 사용하는 관리 화면 |
| 일반 방문자 화면 | 로그인 없이 홈페이지를 조회하는 방문자용 화면               |

## 3. 관리자 화면 목록

### 3.1 관리자 로그인

| ------ | ---------------------------------- |
| 화면명    | 관리자 로그인                            |

로그인 성공 시 관리자 대시보드로 이동하고, 로그인 실패 시 오류 메시지를 표시합니다.

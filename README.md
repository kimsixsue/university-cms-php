# university-cms-php

PHP·MySQL 기반 대학 부속홈페이지 통합관리 CMS 프로젝트입니다.

이 프로젝트는 대학교·공공기관 홈페이지 구축 및 유지보수 업무를 가정하고, 여러 부속 홈페이지를 하나의 관리자 시스템에서 관리할 수 있도록 설계하는 개인 포트폴리오 프로젝트입니다.

## 개발 목적

웹에이전시/SI 환경에서 자주 요구되는 홈페이지 구축, CMS 관리 기능, 게시판 운영, 파일 업로드, 역할관리, 유지보수 흐름을 직접 구현해보기 위해 제작합니다.

단순 게시판 구현이 아니라, 요구사항 정리부터 DB 설계, 관리자 기능 구현, 사용자 화면 구현, 테스트, 실행 방법 문서화까지 처음부터 끝까지 직접 구축하는 것을 목표로 합니다.

## 구현 예정 기능

* 관리자 로그인/로그아웃
* 관리자 역할관리
* 부속 홈페이지 관리
* 메뉴 관리
* 일반 페이지 관리
* 게시판 관리
* 게시글 검색 및 페이징
* 첨부파일 업로드/다운로드
* 배너 및 팝업 관리
* 페이지 수정 이력 관리
* 관리자 작업 로그 기록

## 기술 스택

* PHP 8.x
* MySQL 또는 MariaDB
* PDO
* HTML/CSS
* Bootstrap
* JavaScript
* jQuery
* Docker Compose
* Git/GitHub

## 주의사항

본 프로젝트는 개인 학습 및 포트폴리오 목적의 가상 프로젝트입니다.
